Site owner information

Owner Notes & Safety

For the person who manages the GitHub repository.

What this starter version can do

  • Visitors can open and use the interactive pages.
  • You control the website files through your GitHub account and repository.
  • This version has no public posting, chat, account system, or real admin dashboard.
  • Local notes and scores stay in the current browser; they do not sync between devices.

Important security note

This page is informational, not a secure admin login. Never add a password check only in HTML or JavaScript and assume it protects private controls. For real accounts, shared posts, moderation, or owner-only actions, you need a backend with server-side authentication and access rules.

How to control who edits the website

Keep your GitHub account private, enable two-factor authentication, and do not add other people as repository collaborators unless you want them to edit the code. Public visitors can use the published site but should not be given repository edit access.
